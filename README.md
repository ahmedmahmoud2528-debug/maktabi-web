# مكتبي — تطبيق الويب

واجهة المكتب الافتراضي «مكتبي» (عربي / RTL) مبنية بـ React + Vite من تصميم Figma.

- `npm install` ثم `npm run dev` للتشغيل محليًا.
- `npm run build` لإنتاج نسخة `dist/`.
- النشر تلقائي على GitHub Pages عند الدفع إلى `main`.

المسار الحالي: تسجيل الدخول → اختيار مساحة العمل → المكتب (المخطط، المكاتب، ساعة الدوام، القائمة السياقية، تعيين مالك المكتب، الأشخاص، المحادثة، الدعوة، شريط الاجتماع، تبديل الطوابق).
